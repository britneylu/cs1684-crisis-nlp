# cs1684-crisis-nlp
Evaluating NLP models for identifying humanitarian needs in crisis-related social media posts and their ability to generalize across different crisis events.

## Dataset

We use the [CrisisBench dataset](https://github.com/firojalam/crisis_datasets_benchmarks) for this project.

CrisisBench provides crisis-related social media data for humanitarian information classification. We use the original dataset repository as the source data and conduct our own exploratory analysis, preprocessing, modeling, and evaluation in this repository.
